DOAP project files

DOAP Files

Project data now comes from the ASF release catalog. projects.apache.org no longer reads DOAP files. To change your project's name, description, links, categories, languages or releases, edit it in Apache Trusted Releases (releases.apache.org/projects/<key>?tab=metadata; the key is shown in your project page's address) or in the project: metadata: block of your repository's .asf.yaml. An existing DOAP file can still feed ATR via metadata: doap: <url>.

projects.apache.org used to be built from DOAP files listed in data/projects.xml. It is now built from the ASF release catalog instead, so a DOAP file is no longer needed to appear here. Some projects keep one anyway, for other tools that read DOAP, and Apache Trusted Releases can import project data from a DOAP file linked in .asf.yaml (project: metadata: doap: <url>).

History

During October 2005 a wide ranging discussion was held on the site-dev mailing list aimed at arriving at an archictecture and tools that would allow us to create a project directory web site. A key part of the plans, and one of the biggest stumbling blocks, was the selection of a suitable format of information file that would be the key part.

The result of the discussion was a consensus to use DOAP - "Description Of A Project" which is an RDF based format. The decision was taken for the following reasons:

  • use of an existing format was felt to be important
  • it was becoming more commonly used and therefore had a growing base of support
  • being designed to be extensible, it can be easily adjusted to our needs
