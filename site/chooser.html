Help me choose a project

Answer a few questions and we'll suggest Apache project communities you might enjoy contributing to. Each committee or podling appears once, even if it makes many separate releases. You don't need to write code to contribute - projects need documentation, testing, user support, design, translation and outreach just as much. Skip anything you don't care about.
