DOAP Creation

Create an ASF DOAP File

To be listed on this site, your Apache project must create a DOAP file. The DOAP format is RDF based, so while it is human readable, it's primarily meant to be machine read. Creating the file from scratch can be a little intimidating, so this page will allow you to generate an initial file that can then be edited to suit. Alternatively, you can browse the existing projects for one with similar resources and use its DOAP file as a starting point.

Publish your file

  
Anyone can draft a DOAP file here, but only the project's committers can publish it.
     Not a committer on this project? Send the file to the project's dev@ mailing list
     and they'll take it from there – thank you for helping!

Two steps:

    
    
      
  1. Put the file on your project's website. Commit it to your website source so that it is served at an address like
          https://[committee].apache.org/doap_projectName.rdf.
    
          
    The website is the best place for it: the address won't change when your code repositories are reorganised,
          and it won't be copied into every release tag and branch. Check the address works in a browser before step 2.
    2. 
      
  2. Add it to the projects listing. Add a line to
          data/projects.xml,
          keeping the file in alphabetical order by committee:
    
          
      <location>https://[committee].apache.org/doap_projectName.rdf</location>
    
          
    svn co https://svn.apache.org/repos/asf/comdev/projects.apache.org/trunk/data projects-data
cd projects-data
# edit projects.xml
svn commit -m "Add DOAP file for [project]" projects.xml
    
          
    If you're not comfortable with svn, please contact
          dev@community.apache.org with the address of your file, and we'll add it for you.
    
          
    Your project will appear on this site the next day.

Going further

  
The form covers what this site uses. DOAP has a few more elements (for example wiki or
     audience) that you can add by hand; see the DOAP page and the
     guidelines.

  
Checking your file

  
The file generated here is valid RDF. If you edit it by hand, you can check it with the
     W3C RDF Validator. After it's listed, any problems this site
     finds appear on the validation report.
