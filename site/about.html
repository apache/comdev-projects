About This Website

projects.apache.org is a directory of the Apache Software Foundation's committees, projects, podlings and releases. It is maintained by the Apache Community Development PMC, which discusses it on dev@community.apache.org (archives).

Where the data comes from

Nothing on this site is entered by hand here. Nightly jobs collect it from the ASF's authoritative sources:

DataSource
Projects: names, descriptions, homepages, repositories, bug trackers, mailing lists, categories, languages, releases, active/retired status The ASF release catalog and Apache Trusted Releases (ATR)
Committees: chairs, rosters, charters, reporting schedules, established and retired dates Whimsy (committee-info.json) and the PMC data files in data/committees/
Committers and groups Whimsy public LDAP data
Podlings The Incubator's podlings.xml
Source repositories GitBox and ASF Subversion

Retired projects and Attic projects are not listed, although old links to them still lead to a page marked "Retired".

Updating your project's information

Project information is maintained by each project's committers in Apache Trusted Releases. Each project page has an Edit metadata button that goes to the right place (https://releases.apache.org/projects/<key>?tab=metadata, where the key is the id in the project page's address).

Alternatively, put a project: metadata: block in your Git repository's .asf.yaml and ATR will keep itself in sync (see the .asf.yaml documentation). Projects that still keep a DOAP file can point ATR at it from .asf.yaml instead.

Releases appear automatically once they are in the release catalog; there is nothing extra to record. Changes reach this site the following day.

Not a committer? Suggest the change on the project's dev mailing list.

How the site works

Python cronjobs fetch the sources above and write JSON files, which are committed to Subversion. The pages are static HTML; JavaScript reads the JSON and draws the listings and charts. The JSON files are public, so other tools are welcome to use them.

  • parsecatalog.py: projects and releases, from the release catalog and ATR
  • parsecommitteeinfo.py: committees, from Whimsy and the PMC data files
  • parsecommitters.py: people and groups, from Whimsy
  • podlings.py: podlings, from the Incubator
  • generaterepos.py: source repositories
  • buildchooser.py: data for the "Help me choose a project" page

Details are in scripts/README.txt and STRUCTURE.txt.

Reporting problems

Problems with the site itself: open a COMDEV Jira issue in the "Projects Tool" component, or write to dev@community.apache.org.

Wrong information about a project: the project's committers can fix it in ATR (see above). ComDev doesn't maintain project data.
